# Freight Rate Prediction

## Project Overview

This project develops a machine learning regression pipeline to predict freight rates using historical shipment data.

The objective is to estimate the posted freight rate based on shipment distance, pickup and delivery locations, equipment type, weight, date-related features and available market indicators.

The project also generates daily freight-rate predictions for a specified December route.

## Dataset

| Dataset | Rows | Description |
|---|---:|---|
| Training data | 48,000 | Labelled shipment records from January–October 2025 |
| Validation data | 12,000 | Unlabelled November–December 2025 shipment records |
| December chart input | 31 | Daily forecast inputs for a fixed route |

The target variable is `posted_rate`.

## Methodology

### 1. Exploratory Data Analysis

- Examined dataset structure, data types, missing values and date ranges.
- Analysed target distribution and numerical feature correlations.
- Observed a strong positive correlation between distance and posted rate.
- Investigated an engineered rate factor:

  `rate_factor = posted_rate / (distance * quote_signal)`

- Retained rare high-rate observations rather than removing them without evidence that they were invalid.

### 2. Data Preparation

- Converted date into month, day of year and day of week.
- Converted negative shipment weights to absolute values.
- Imputed missing numerical values using training-data medians.
- Used pickup, delivery and equipment as categorical features.
- Used a chronological split to evaluate future-period prediction performance.

### 3. Model Development

CatBoost Regressor was used because it supports categorical features and can learn nonlinear relationships.

Three approaches were evaluated for the main validation task:

1. **Direct CatBoost:** predicts `posted_rate`.
2. **Rate-factor CatBoost:** predicts `rate_factor`, then reconstructs the freight rate using distance and quote signal.
3. **Ensemble:** combines the direct and rate-factor predictions.

The selected ensemble uses 25% direct-model predictions and 75% rate-factor-model predictions.

### 4. December Forecasting

The December input does not contain `market_index` or `quote_signal`. Therefore, a separate model was developed using only the available December features.

The December distance factor is defined as:

`distance_factor = posted_rate / distance`

The model predicts this factor and reconstructs the freight rate by multiplying it by distance.

The distance-factor model performed better than the direct model and tested blends on the local chronological holdout.

## Local Validation Results

The main model comparison used January–August 2025 for training and September–October 2025 for local validation.

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Dummy baseline | $1,178.80 | $1,526.23 | -0.0002 |
| Direct CatBoost | $120.55 | $634.44 | 0.8272 |
| Rate-factor CatBoost | $114.18 | $633.28 | 0.8278 |
| 25:75 ensemble | **$111.61** | **$632.88** | **0.8280** |

For the December-compatible experiment:

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Direct CatBoost | $123.61 | $634.59 | 0.8271 |
| Distance-factor CatBoost | **$109.54** | **$632.13** | **0.8284** |
| 25:75 ensemble | $110.5405 | $632.2107 | $0.8284

These are local chronological holdout results, not hidden Spotter validation metrics.

## Final Outputs

- `validation_predictions.csv`: 12,000 predicted freight rates with their corresponding load IDs.
- `december_chart_inputs.csv`: 31 daily predictions for the specified December route.
- `candidate_december.png`: chart generated by the provided scorer.

The provided scorer successfully validated the 12,000 validation predictions and 31 December predictions.

## Limitations

- Rare high-rate shipments were difficult to predict accurately.
- The local validation results may not exactly represent hidden-test performance.
- The available features may not capture all factors responsible for unusually high freight rates.
